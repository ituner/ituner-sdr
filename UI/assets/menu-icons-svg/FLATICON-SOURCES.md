# Flaticon menu icon sources

- `dual.png`: [Split icon 16159537](https://www.flaticon.com/free-icon/split_16159537), rotated 90 degrees clockwise, widened, reduced in height, adjusted to a light line weight, and recolored for the dark navigation rail.
- `info.png`: [IP address icon 17219660](https://www.flaticon.com/free-icon/ip-adress_17219660), recolored for the dark navigation rail.
- `frequency-chevron.png`: [Down chevron icon 3759325](https://www.flaticon.com/free-icon/down-chevron_3759325), recolored for the dark frequency drawer; the UP control rotates the same artwork 180 degrees at runtime.

The runtime copies are 64×64 transparent PNG files in `UI/assets/menu-icons/`
and `assets/menu-icons/`.
